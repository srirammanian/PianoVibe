## 3. Contemporary Pop Songs

### Finding: NO VIABLE PUBLIC DOMAIN POP MIDI SOURCES

**Problem:** Contemporary pop songs (post-1928) are almost never public domain. Copyright lasts 70+ years after composer's death.

### Options to Consider:

| Option | Pros | Cons |
|--------|------|------|
| **Create your own MIDIs** | Full control, unique content | Time-intensive |
| **Commission transcriptions** | Professional quality | Expensive |
| **Use MIDI converters** | Can convert audio to MIDI | Quality varies |
| **Creative Commons only** | Limited selection exists | Rare for pop |
| **License commercially** | Professional tracks | Costly, restrictions |

### Related Resources (for conversion/generation):
- **Lakh MIDI Dataset** - 178K MIDIs, mostly pop, many unlicensed
- **Rock-Piano-MIDI-Dataset** - https://github.com/asigalov61/Rock-Piano-MIDI-Dataset
- **Audio-to-MIDI converters** - Could generate from YouTube covers

### Recommendation:
For PianoVibe, consider:
1. Classical music (safe, abundant)
2. Public domain folk songs
3. User-generated MIDI uploads
4. Simple original compositions

## 4. Licensing Considerations

### Source Licensing Matrix

| Source | License | Commercial Use | Attribution Required |
|--------|---------|---------------|---------------------|
| **ClassicalPianoMIDI-dataset** | MIT (code) | Depends on piano-midi.de | Yes |
| **piano-midi.de** | Not clearly stated | **Non-commercial implied** | Yes |
| **Mutopia Project** | Public Domain | Yes | Not required |
| **IMSLP/Petrucci** | Varies by score | Varies | Check each score |
| **MAESTRO Dataset** | CC BY-NC-SA 4.0 | No | Yes |

### piano-midi.de Status
- **Not explicitly public domain**
- MIDI files are **user-submitted transcriptions**
- Use is likely **non-commercial only**
- Contact site owner for commercial licensing

### Mutopia Project (mutopiaproject.org)
- **True public domain** for scores they typeset
- MIDI files also public domain
- **BEST option for truly public domain music**
- Smaller collection than piano-midi.de

### Recommendation for PianoVibe:
1. Use ClassicalPianoMIDI for initial content (acknowledge source)
2. Seek explicit permission from piano-midi.de for commercial use
3. Add Mutopia Project MIDIs for clearly public domain songs
4. Build pipeline for user-generated content

## 5. Fingering Data

### Current State: NO PUBLIC FINGERING DATASET EXISTS

Standard MIDI files (SMF) have no standard fingering channel.

### Existing Tools:

| Tool | Repository | Description |
|------|------------|-------------|
| **Piano Vision Fingering Generator** | TomMeyer/piano-vision-fingering-generator | CLI tool using PianoPlayer |
| **PianoPlayer** | marcomusy/pianoplayer | Python library for generating fingerings |
| **FingOptim** | hanrodz/fingoptim | Optimal fingering finder |

### How PianoPlayer Works:
- Uses algorithmic approach to generate fingering suggestions
- Based on hand size (XXS to XXL)
- Not 100% accurate but usable for learning

### Recommendation for PianoVibe:
1. **Integrate PianoPlayer** as a fingering engine
2. Generate fingering on-demand when users select songs
3. Allow users to **override/correct fingering** (crowdsource improvements)
4. Store fingering data in custom MIDI extension or separate JSON file
